# Daily Devotional Panchang Shorts Engine

Automated YouTube Shorts pipeline powered by Google Gemini, Imagen, Remotion, and GitHub Actions.

## Project setup

1. Install Node.js 20 or later.
2. Clone this repository and run `npm install`.
3. Set `GEMINI_API_KEY` in your local environment.
4. Add your Google OAuth desktop client file as `client_secret.json` in the project root.
5. Complete YouTube OAuth locally and save the resulting `token.json` in the project root.
6. Preview the Remotion composition with `npm run dev`.
7. Run the pipeline locally with `npm start`.

## GitHub Actions secrets

In **Settings → Secrets and variables → Actions**, add:

- `GEMINI_API_KEY` — your Google AI API key.
- `CLIENT_SECRET_JSON` — the complete contents of your Google OAuth client JSON file.
- `TOKEN_JSON` — the complete contents of your OAuth token JSON file.

Do not commit `client_secret.json`, `token.json`, API keys, or other credentials. These files are excluded by `.gitignore`.

## Scheduled runs

The workflow is configured for 06:00, 12:30, and 18:30 India Standard Time (UTC schedule: 00:30, 07:00, and 13:00). You can also start it manually from the **Actions** tab using **Daily Shorts Publisher → Run workflow**.

## Important notes

- The workflow attempts to publish directly to YouTube as **public**. Test locally or change the privacy setting before enabling scheduled publishing.
- Google API quotas, API/model availability, billing, OAuth token expiry, and GitHub Actions limits can prevent a run from completing. A successful workflow setup does not guarantee that every scheduled upload will publish.
- The current Remotion composition is 15 seconds long (450 frames at 30 fps).
- `public/` is reserved for static assets. The supplied pipeline does not currently load or mix `devotional_bg.mp3`; adding an audio file alone will not add music to the rendered video.
- Panchang and muhurat information generated by an AI model must be independently verified against a reliable regional Panchang before publication.


## 60-second Panchang video and narration

The Remotion composition targets 60 seconds (1080x1920 at 30 fps) and alternates traditional maroon/gold and modern dark-card visual treatments by section. The render pipeline generates Hindi narration with Gemini TTS before rendering; a valid GEMINI_API_KEY is required.

## Global Panchang location

Set these GitHub Actions repository variables under Settings → Secrets and variables → Actions → Variables, or export them locally:

- PANCHANG_LAT: latitude in decimal degrees
- PANCHANG_LON: longitude in decimal degrees
- PANCHANG_TZ: UTC offset in hours (5.5, -4, 9, etc.)
- PANCHANG_LOCATION: city/country label shown in the video
- PANCHANG_TIMEZONE_LABEL: timezone label shown in the video

Defaults are Ujjain, India (23.1765, 75.7885, UTC+5:30). The calculator accepts a fixed UTC offset, not an IANA timezone database. Update PANCHANG_TZ for daylight-saving changes. Independently verify local Panchang timings before publishing.


## Static Panchang poster video

The 60-second Remotion composition holds the complete Panchang poster layout on screen for the full duration. Text, date, cards and timings are static: there is no zoom, camera movement, scene transition or voice-over. Only decorative artwork has subtle motion (diya flames, hanging bells, ambient glow and drifting light/flower particles). The only audio track is the soft generated devotional ambient music.

The video does not print a city or viewer location. **Calculation caveat:** sunrise/sunset and sunrise-based muhurat timings are location-dependent. The engine still needs one configured reference coordinate/timezone to calculate those values; hiding the location label does not make the timings universally correct for every viewer. Choose a clearly documented reference Panchang or publish location-specific versions if exact local timings are required.


### Audio: Hindi narration + soft devotional music

The static poster video includes two simultaneous audio layers:
- Hindi spoken Panchang narration generated through Gemini 2.5 Flash TTS (voice: Kore).
- Soft devotional ambient instrumental with temple-bell accents, mixed at 10% volume under the narration.

Narration is normalized and padded/trimmed to the 60-second composition. The TTS step runs before Remotion rendering and requires the `GEMINI_API_KEY` Actions secret. The poster layout and text remain static; only decorative artwork animates.
